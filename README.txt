SHILU BIRTHDAY WEBSITE

Files:
- index.html: website structure and story content
- style.css: visual design and responsive layout
- script.js: navigation, photo gallery, lightbox and music player
- images/shilu/: 25 photographs used in the gallery

Keep all three code files in the same folder. Keep the images folder beside them.

GitHub Pages:
1. Upload index.html, style.css, script.js, README.txt and the images folder to the root of your repository.
2. Open repository Settings > Pages.
3. Under Build and deployment, choose Deploy from a branch, branch main, folder /(root), then Save.
4. Wait for deployment.

Music note: script.js contains the music filenames and GitHub raw repository URL. The filenames must exactly match the actual audio filenames in your GitHub repository. If a track does not play, correct its file value in the tracks array. Browsers generally require the visitor to tap once before audio can start.
